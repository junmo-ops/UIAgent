# 需求整理

1. 说明正在使用“需求整理”技能。
2. 从用户输入和最近对话中提取目标、范围、交互流程和验收要点。不要虚构用户没有确认的业务规则；不明确的内容标为待确认。
3. 需要修改页面时仍按编辑 Agent 的声明意图、修改和校验流程执行。本文档不是页面修改已完成的证据。
4. 用户要求整理或生成文档时，选择一个可用脚本，调用 `run_skill_script`。Python 可用时使用 `scripts/render.py`；否则用等价的 `scripts/render.mjs`，不需要两个都运行。
5. args 格式如下，inputs 可为空：

```json
{"title":"需求说明","sections":[{"heading":"目标","items":["用户已确认的目标"]},{"heading":"验收要点","items":["可验证的预期行为"]}]}
```

6. 脚本返回 `requirements.md` 的正文。成功时在回答中展示文档内容；失败时说明失败原因，不声称已生成。当前没有下载链接，不要虚构链接或暴露服务器临时路径。
