# 真实资产登记（R1 / R2）

当前 R1、R2 均未提供。对应 C07/C08/E13/E14 为 blocked。

## 收集原则

- 由你从获准用于内部评估的页面中选择两类不同机制：例如真实组件库表单/表格，以及微前端或复杂滚动工作台。不要只是同一模板换文案。
- 优先使用非生产测试页面和虚构账号。先脱敏再保存，清除真实姓名、客户/账号信息、内部密钥、Cookie、Authorization、带签名的资源 URL。
- 公司页面、日志、截图、快照和内部 URL 只存授权的内部位置，不上传公网或提交公开仓库。不要放进 demo 的 public 目录。
- 对动态页面保存“采集前状态截图 + 操作说明 + 经授权的页面资产版本”。只拿插件导出的副本当原页，会绕过捕获缺陷，不足以评估 C07/C08。
- 无法冻结原页时，标注 live-only，每批重新保存原页证据，不能把不同时间的网站直接当作严格 A/B。
- 如果拿不到某机制，列为未覆盖，不用合成页冒充。
