# UI 辅助需求编写插件 Demo 需求确认稿

## 1. 目标用户与核心场景

目标用户是产品经理。

典型场景：产品经理在缺少设计师支持时，需要在已有 PC 页面中增加或调整 UI。仅靠文字描述容易产生理解偏差，研发需要与产品经理反复沟通位置、内容和控件状态。产品经理希望直接在页面上生成静态 UI 改动示意，并将截图交给研发理解需求。

首个代表性案例：产品经理需要在现有页面增加一个筛选项，指定它相对某个已有元素的位置、包含的选项以及希望展示的状态，再通过截图向研发说明预期效果。

## 2. 需要解决的问题

- 降低简单 UI 需求的原型制作成本。
- 将抽象文字描述转化为直观的页面示意。
- 减少产品与研发对位置、内容、样式和控件状态的反复确认。
- 允许产品经理通过多轮自然语言快速修正首次生成结果。

Demo 验证的是“辅助表达 UI 需求”的可行性，不是生成生产代码或实现真实业务功能。

## 3. Demo 核心流程

1. 产品经理使用最新版 Chrome 打开固定测试页面。
2. 打开插件并进入元素选取模式。
3. 点击一个已有页面元素，将其作为编辑对象和位置锚点。
4. 插件获取选中元素、相邻元素、局部容器结构及可见样式。
5. 用户输入自然语言修改要求，例如“在这个搜索框右侧添加一个状态下拉框”。
6. 专用 Agent 将要求转换成受控的结构化操作。
7. 插件校验操作并在当前页面执行。
8. 用户继续通过多轮对话调整内容、样式、位置或展示状态。
9. 用户可以逐步撤销、重做；涉及删除已有元素时必须先确认。
10. 用户在插件中预览结果，并导出当前浏览器可视区域截图。

首次选中元素后持续编辑同一区域；需要切换编辑对象时，由用户重新选择元素。

## 4. 功能范围

### 4.1 基础组件

首期支持：

- 按钮
- 文本
- 链接
- 单选
- 多选
- 下拉框
- 输入框

### 4.2 编辑操作

首期支持：

- 在选中元素的上、下、左、右添加组件。
- 修改选中元素或本轮新增元素的内容。
- 调整颜色、尺寸、间距等基础外观。
- 调整新增元素的位置。
- 删除选中元素或本轮新增元素。
- 按用户要求展示指定静态状态，例如展开下拉框并显示选项。
- 在同一区域进行多轮连续调整。
- 逐步撤销和重做当前会话中的修改。
- 在插件内预览修改结果。
- 导出当前浏览器可视区域截图。

新增内容应自动复用测试页面中已有组件和视觉样式。

## 5. 暂不包含

- 任意 UI 或任意 HTML 结构生成。
- 真实筛选、查询等业务逻辑。
- 接口调用和真实业务提交。
- 跨页面流程。
- 任意 JavaScript 或脚本执行。
- 直接修改或生成生产项目代码。
- 页面刷新后的修改恢复。
- React/Vue 等框架重新渲染后的修改保持。
- 保存和重放历史编辑会话。
- 完整页面长截图。
- 任意网站适配。
- Chrome 以外的浏览器支持。
- 完整产品规划及大规模通用化建设。

## 6. 关键技术约束

- 仅支持最新版 Chrome。
- 首期运行于专门搭建的本地或测试环境页面。
- 测试页面需要提供基础组件及可复用的视觉样式。
- AI 只接收局部上下文，不读取整个页面。
- 模型尚未确定，需要设计可替换的模型调用层。
- Agent 输出受控的结构化操作，不直接操作 DOM。
- 插件负责验证、执行结构化操作并维护编辑历史。
- 为插入相邻组件，可对选中元素的父容器执行受控插入操作，但不能任意修改父容器。
- 修改只保证在当前页面会话中有效。
- Agent 以变更规划为职责，不具备任意浏览器操作或脚本执行能力。

## 7. 安全边界

- Agent 默认只能修改当前选中元素和本轮新增元素。
- 相邻元素仅用于理解上下文，不能被隐式修改。
- 删除已有元素前必须展示删除对象并获得用户确认。
- 模糊、越界或无法校验的指令不得修改页面。
- 执行失败时说明原因，并要求用户补充或改写。
- 禁止执行模型生成的任意脚本。
- 禁止调用或提交真实业务接口。
- 结构化操作必须经过插件白名单及参数校验。
- Demo 测试页面不包含敏感信息，允许将局部 DOM 和可见样式发送给模型。

## 8. 验收标准

- 能完成添加组件、修改已有元素和删除已有元素三类代表性任务。
- 基础组件集中的每类组件至少可以成功添加一次。
- 支持至少三轮连续自然语言调整，并始终作用于正确对象。
- 支持调整内容、基础外观、相对位置和静态展示状态。
- 支持逐步撤销、重做，页面结果恢复正确。
- 删除已有元素前必定出现确认。
- 模糊、越界或校验失败的指令不会改变页面。
- 新增组件能合理复用测试页面的现有样式。
- 可以导出内容清晰、结果正确的浏览器可视区域截图。
- 不执行任意脚本，不触发真实接口或业务提交。

## 9. 尚未解决的问题

以下问题留到实现前或实现过程中进一步确定：

- 使用的具体模型、服务商和鉴权方式。
- 单轮生成的最终响应时间验收值。
- 截图文件的默认命名细节。
- 固定测试页面最终采用的组件库和具体业务页面样式。
