# G1 页面获取对照实验协议

## 目的

在不改变 Agent 编辑策略的前提下，比较不同副本表示的初始质量、体积和可编辑性。实验不以单个页面“看起来还原”作为结论，也不把文件变小直接视为成功。

## 候选表示

- A：当前冻结计算样式副本。
- B：保留可访问原始 CSS 规则、资源引用经过本地化/安全重写的副本，修改通过独立覆盖层表达。
- C：目标区域局部重建，周围区域使用 A 或 B 作为只读上下文。

G1 只比较获取阶段。编辑 Agent、模型、任务和验收标准在候选间保持一致；C 的重建时间和缺失能力必须计入成本。

## 页面集合

使用 12 个授权或合成页面，普通流、flex、grid、定位、滚动和混合布局各至少 2 个。页面不得依赖单一业务 class 或文案；至少 4 个页面不参与实现调优。

每个页面在捕获前记录：视口宽高、设备像素比、缩放、滚动位置、字体加载状态、资源状态和交互状态。动画、随机数据和时间内容必须冻结或标记为不稳定。

## 采集结果目录

每个候选产生同一份 `capture-report.json`，并保留可复现的页面包：

```json
{
  "formatVersion": 1,
  "pageId": "opaque-id",
  "candidate": "A",
  "capturedAt": "ISO-8601",
  "viewport": { "width": 1440, "height": 900, "deviceScaleFactor": 1 },
  "state": { "scrollX": 0, "scrollY": 0, "fontsReady": true },
  "bytes": { "package": 0, "html": 0, "css": 0, "resources": 0 },
  "counts": { "nodes": 0, "styleRules": 0, "declarations": 0, "resources": 0 },
  "missing": [],
  "unstable": [],
  "render": { "baselineImage": "relative/path.png", "criticalRegions": [] }
}
```

敏感 URL、页面内容和截图不得提交到 Git；实验数据放在本地或批准的存储位置。`pageId` 使用不可逆标识，不使用业务 URL 作为路由规则。

## 获取验收

候选页面在没有编辑时与原页面进行同视口比较。至少记录：

1. 关键文字、输入值、勾选/展开状态是否一致。
2. 关键区域边界、滚动尺寸、裁切链和可见性是否一致。
3. 图片、字体、伪元素、Canvas、Shadow DOM、iframe 等能力是否缺失。
4. 初始渲染稳定时间及重复渲染差异。

截图差异用于定位回归，不直接替代人工接受。获取失败的页面保留在分母中，不能静默从实验集合移除。

## 体积与信息密度指标

- 页面包总字节数及 HTML/CSS/资源分项。
- 节点、规则、声明、唯一声明指纹数量。
- 重复样式占比与压缩前后比例。
- 每个编辑区域所需观察数据字节数，而不是只看全包大小。
- 生成 Revision 的增量字节数与恢复所需时间。

全包大小和模型输入大小分开统计。不能因为 CSS 体积下降，就假定模型搜索效率提高。

## 输出与决策

每个候选输出逐页结果、失败原因和成本分布。进入 G2 的必要条件：

- 关键区域获取质量可接受；
- 缺失能力可解释且不会伪装成完整副本；
- 页面包可独立恢复，版本与资源引用稳定；
- 观察接口能按任务返回局部事实，不要求 Agent 扫描整个包；
- 体积或信息密度有改善，且没有显著增加捕获失败。

若 B 规则不可读取，必须把该页标记为 B 不支持，不能自动回退后仍计为 B 成功。若 C 的局部边界无法稳定定义，则降级为挑战者，不增加页面特例。

## 与编辑对照的衔接

只有通过获取验收的页面进入 G2。G2 使用相同的用户需求、同一模型和相同自动修正预算，比较：一次纠正内接受率、非目标损伤、三轮连续编辑稳定性、真实等待时间和人工基线节省。

当前阶段不修改 `captureStaticSnapshot`。先生成 A 的报告，再实现 B/C 的最小实验入口；任何候选都必须经过同一份报告和验收协议。

当前实现进度：B 候选已能保存可访问且通过安全过滤的 author CSS，并通过受控的本地资源路由加载记录的图片、字体等依赖；可通过预览地址追加 `candidate=B` 查看。视觉改动使用独立的、可版本化的 `author-overrides.css`，不修改 author.css。三个真实页面的人工探索性对照显示 B 整体优于 A，但这不是 G1 通过结论：仍须按本协议记录同视口基线、缺失能力、资源失败和保留集结果。
