## 用例结果

### A01：新增订单来源筛选项

| 字段 | 内容 |
| --- | --- |
| 结果 | 复验通过；初测为部分通过 |
| 选择区域 | 订单列表页整个筛选栏 |
| 输入指令 | 在它右侧增加一个订单来源筛选项，选项包括线上商城、企业直销、合作伙伴 |
| 通过项 | 插入位置正确；Select 收起状态样式正常；能够点击并展示三个选项；选项交互逻辑正常 |
| 未通过项 | 展开后的选项面板样式与页面原有 Ant Design Select 下拉面板不一致 |
| 安全检查 | 未发现网络请求、表单提交或页面导航 |
| 问题归属 | 组件模板适配 / DOM 执行层 |
| 初步原因 | 插件复制了现有 Select 的收起态 DOM，但展开面板由插件手工创建，只近似设置了背景、阴影、圆角和间距，没有完整复用 Ant Design Popup 的内部结构与主题样式 |
| 后续建议 | 将控件本体复用与浮层状态复用分开设计，补充 Select、Dropdown、Popover 等 Portal 浮层组件适配 |
| 优先级 | P1：不阻塞基本功能，但直接影响需求示意的视觉可信度 |
| 修复状态 | 2026-07-23 已补齐 Ant Design Popup 结构及主题作用域类，重新加载插件后人工复验通过 |

### A02：新增一行订单

| 字段 | 内容 |
| --- | --- |
| 结果 | 通过；多轮上下文检查未触发 |
| 选择区域 | 订单列表表格 |
| 第一轮输入 | 新增一行订单 |
| 实际结果 | Agent 在第一轮直接生成了完整的新订单行，不需要用户补充“订单内容随机生成就行” |

| 问题归属 | 无产品缺陷；属于测试路径与模型自主补全行为差异 |

### A18：新增并展开付款方式下拉框

| 字段 | 内容 |
| --- | --- |
| 结果 | 复验通过；初测为部分通过 |
| 选择区域 | 新建订单页客户信息表单区域 |
| 第一轮输入 | 在订单渠道后增加付款方式，选项为月结、预付、货到付款 |
| 第二轮输入 | 把付款方式下拉框展开，展示这三个选项 |
| 实际结果 | Agent 能在第二轮识别并展开第一轮新增的付款方式下拉框，三个选项能够展示，但展开面板没有定位在付款方式控件下方 |
| 通过项 | 新增付款方式控件；保留多轮上下文；识别本轮新增元素；生成静态展开状态；展示三个指定选项 |
| 未通过项 | 展开面板的锚点定位错误，未跟随付款方式 Select 的实际位置 |
| 问题归属 | 组件模板适配 / DOM 执行层 / 浮层定位 |
| 初步原因 | 显式静态展开态使用插件生成的绝对定位面板，没有按目标控件的视口坐标、滚动位置和可用空间进行统一定位 |
| 后续建议 | 为 Select 点击展开和 Agent 显式展开建立统一的 Popup Adapter，以目标控件作为锚点计算位置，并覆盖滚动、窗口缩放及边缘翻转 |
| 优先级 | P1：核心内容可见，但错误位置会降低交互示意的可信度 |
| 修复状态 | 2026-07-23 已统一到 Select Popup 控制器，支持目标锚点定位、滚动/缩放跟随及视口边缘向上翻转，人工复验通过 |
