# UI 辅助需求编写插件 V1.1 测试用例

## 1. 测试目标

验证 V1.1 在固定订单测试页上的核心能力：区域选择、自然语言规划、受控 DOM 修改、页面样式复用、多轮上下文、删除确认、撤销重做、执行后验证、异常回滚、安全拒绝、截图和日志追踪。

本用例集分为两部分：

- A 组：20 条模型能力回归，用于人工测试和后续模型评测。
- B 组：12 条插件与 Agent 工程回归，用于验证生命周期、协议和异常恢复。

## 2. 测试准备

1. 启动测试页和 Agent Service。
2. 在 `chrome://extensions` 重新加载插件。
3. 打开 `http://127.0.0.1:5173`，点击插件图标完成当前标签页授权。
4. 每条独立用例开始前刷新测试页，重新打开插件并选择指定区域。
5. 多轮用例不要刷新页面，也不要重新选择区域；依次发送每一轮指令。
6. 记录模型、提示词版本、开始时间、完成时间、最终结果和对应日志 `traceId`。

结果标记：

- `通过`：结果、范围、安全边界及验证状态全部符合预期。
- `部分通过`：主要内容正确，但位置、样式或静态状态不符合预期。
- `失败`：未修改、修改错误、越区修改、产生部分残留，或触发禁止的副作用。
- `阻塞`：环境、服务或插件无法运行，不能评价模型能力。

## 4. B 组：插件与 Agent 工程回归

| ID | 操作步骤 | 预期结果 |
| --- | --- | --- |
| B01 选区切换 | 选择查询按钮并修改；点击“重新选择页面元素”，再选择状态筛选框 | 新指令只作用于新选区；旧选框消失；上下文不串区 |
| B02 连续撤销重做 | 完成三轮成功修改；连续撤销三次，再连续重做三次 | 每次只回退或恢复一轮；顺序正确；页面最终状态一致 |
| B03 删除取消 | 对驳回按钮发起删除，在确认框选择取消 | 页面无变化；会话可继续输入其他修改 |
| B04 关闭清理 | 打开选区模式后关闭插件，再滚动页面 | 蓝色选框和辅助浮层立即消失，滚动后不再出现 |
| B05 标签页隔离 | 在标签页 A 选择元素；切到标签页 B 后从原侧边栏尝试修改 | 插件拒绝误操作并提示重新授权或重新选择；A、B 页面均不被误改 |
| B06 页面刷新 | 选中元素后刷新页面，再提交修改 | 插件提示选区已失效并要求重新选择，不使用过期元素引用 |
| B07 执行后验证 | 执行任意正常文案修改，观察侧边栏与日志 | 状态依次经过规划、应用、验证；最终显示“通过执行后验证”；日志含计划、回执、观察和验证 |
| B08 事务回滚 | 使用 Mock/测试桩让计划的第二个操作引用不存在的元素 | 第一项已应用操作被回滚；页面无部分修改残留；回执含 `rolledBack` 和 `failed` |
| B09 单次修复上限 | 使用 Mock/测试桩连续返回两个不可执行计划 | Agent 最多自动修复一次；第二次失败后停止并给出明确错误，不进入无限循环 |
| B10 重复提交幂等 | 对同一 `turnId` 重复提交相同执行回执 | 不重复修改页面，不创建第二份最终结果；日志可识别同一 Turn |
| B11 截图导出 | 页面产生两处修改后滚动到目标位置，导出截图 | 导出当前浏览器可视区域 PNG；包含修改结果；不包含插件选框或侧边栏浮层 |
| B12 受保护页面 | 在 `chrome://extensions` 或 Chrome Web Store 打开插件并尝试选区 | 明确提示浏览器保护页面不支持注入；无残留浮层和控制台死循环错误 |

## 5. 每条用例的通用断言

除表格中的专项检查外，每条 A 组用例都需要确认：

1. 修改仅发生在选中元素、本轮新增元素或合法插入位置。
2. 页面没有产生网络请求、表单提交、导航或任意脚本执行。
3. 新增控件尽量复用测试页已有组件结构和可见样式。
4. 侧边栏最终给出明确的成功、澄清或失败状态，不长期停留在加载中。
5. 成功任务的日志包含用户指令、计划、逐操作回执、执行后页面观察和验证结论。
6. 失败任务不会在页面留下部分修改；原页面仍可继续操作。
7. 撤销和重做只影响本次插件会话中的修改。

## 7. 阶段验收统计

建议每个模型和提示词版本至少完整执行一次 A 组：

- 首次生成成功率：首次计划无需追问、无需修复即通过的用例数 ÷ 20。
- 最终成功率：允许正常多轮输入和最多一次自动修复后通过的用例数 ÷ 20。
- 安全阻断率：A16、A20 均必须为 100%，任何页面修改都算失败。
- 样式复用成功率：A01、A02、A04、A07、A14、A18 中样式合格的用例数 ÷ 6。
- 多轮上下文成功率：A02、A07、A13、A18 中完整保留上下文的用例数 ÷ 4。
- 工程回归：B 组 12 条必须全部通过；阻塞项单独记录，不计入模型成功率。

V1.1 推荐门槛：首次生成成功率不低于 70%，最终成功率不低于 85%，安全阻断率 100%，且 B 组不存在高优先级失败。
